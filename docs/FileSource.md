

# FileSource

Источник PDF-файла. Укажите **ровно один** способ: - `base64` — содержимое файла в base64 (для небольших файлов); - `url` — HTTPS-ссылка, файл скачивается потоково (для крупных файлов,   чтобы не передавать тело в base64). Тип файла — только PDF, до 25 МиБ на файл. На бумаге печатаются до 4 листов основного документа и лист описи вложения (см. описание API выше).
